## How to count so it only happens once

- Count by the sheet order, hidden first. Tick each row as you go.
- Apparel: count by size, not just total. Variance by size matters for clearance pricing.
- Packs: a "pack" is one unit. If packs are broken up into loose pins or tags, count the loose pieces under "Not on this list."
- Damaged or unsellable: count it, note it. It still comes off the shelf.
- Photo of each shelf or bin when done. Fast backup if a number looks wrong later.
- Done means every row has a number. Not "most."
